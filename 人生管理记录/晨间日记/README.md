# 晨间日记

晨间日记是每天的入口，不是所有事情的容器。

## 记录原则

- 只写今天需要启动的内容。
- 三只青蛙可以看见所有未完成项，优先处理旧负债，再决定今天新增什么。
- 本月重要事项显示所有未完成事项；完成后在晨间日记里勾掉，底层仍回写到月度事项数据库。
- 三个数据库管理页按对象维护：青蛙是任务表，习惯是定义 + 月度矩阵，月度事项是事项表；日期和月份只做关联字段。
- 复杂想法链接到对应领域或项目。
- 不追求完整，先保持可写。
- 允许随笔，但不要把长期规划全部塞进当天日记。

## 可用结构

- 今天是什么日子：天气 / 情绪 / 身体感受。
- 今天要吃掉哪三只青蛙。
- 今天想成为一个什么样的人。
- 昨天习惯坚持得怎么样。
- 昨天有没有日拱一卒。
- 本月重要的几件事。
- 年度目标。
- 其他想记录的。
