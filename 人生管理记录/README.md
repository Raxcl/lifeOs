# 人生管理记录

这里先作为人生管理系统的记录区。它是权宜之计，目标是先行动起来，把混乱的想法放到合适的位置；等正式系统做好后，再把这些记录迁移或接入进去。

## 使用规则

- 晨间日记负责启动今天，不承载所有细节。
- 人生领域记录长期经营的方向，比如主业、副业、健身、财富。
- 具体项目记录有明确结果和结束点的事情，比如一次求职、一次副业验证、一次外出摄影。
- 复盘总结负责把经历变成判断力。
- 资料索引只放外链、路径和简要说明，不搬运大量素材。

## 目录

- `晨间日记`: 晨间日记和日常记录。
- `人生领域`: 长期人生领域。
- `具体项目`: 具体推进项目。
- `复盘总结`: 周复盘、月复盘和阶段总结。
- `资料索引`: 外部资料、素材和链接索引。
